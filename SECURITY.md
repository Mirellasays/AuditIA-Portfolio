# Security and Responsible Disclosure

This public repository contains portfolio documentation only and should not contain credentials, patient-identifiable information, confidential employer material, production data, or security-sensitive implementation details.

If you identify accidental disclosure of sensitive information, a privacy concern, or a safety/security issue, please contact the repository owner privately.

Please do not publish personal data, credentials, confidential information, or exploit details in a public GitHub issue.

This responsible-disclosure request does not create a bug-bounty program or promise compensation.
