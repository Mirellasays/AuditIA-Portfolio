# AuditIA Portfolio

**Clinical AI Evaluation for Medical Auditing**

AuditIA is an independent portfolio project by **Mirella Batista Cruz, MD**, focused on evaluating generative AI in high-stakes medical-auditing workflows.

> **Status:** Development and exploratory evaluation. AuditIA is not a clinically validated medical device and is not intended for autonomous coverage or patient-care decisions.

## Purpose

Medical auditing requires structured evidence review, explicit criteria, uncertainty management, traceability, and accountable human judgment. AuditIA explores how these principles can inform safer evaluation of Clinical AI systems.

This public repository demonstrates the project's **evaluation philosophy, safety priorities, and governance approach**. Complete prompts, scoring rubrics, benchmark datasets, internal test suites, implementation details, and proprietary workflow logic are intentionally not published.

## Evaluation areas

- Evidence grounding
- Logical consistency
- Missing-information handling
- Context and case isolation
- Robustness to untrusted source content
- Uncertainty and escalation
- Traceability and human oversight

## Safety testing

Private development includes synthetic adversarial and edge-case testing involving incomplete evidence, logical-rule handling, context isolation, and instruction robustness.

The public portfolio describes evaluation categories without disclosing the complete benchmark, prompts, expected-output specifications, or scoring rules.

## Design principles

**Evidence over inference · Traceability over fluency · Uncertainty over false certainty · Human accountability over automation**

## Public vs. private boundary

**Public:** project purpose, high-level methodology, safety principles, selected evaluation categories, limitations.

**Private:** full prompts, system instructions, proprietary workflow logic, detailed scoring rubrics, complete benchmark/test set, unpublished analyses, implementation artifacts, and confidential materials.
